# Protein Index

Protein Index is a searchable reference for comparing packaged protein foods
available from configured Indian data sources.

It normalizes products and keeps the evidence state attached to nutrition,
ingredients, and identity. Verified label facts remain separate from
discovery-only data, conflicting values are withheld from trusted comparisons,
and missing values stay missing.

## Use it to

- Search by product, brand, or GTIN.
- Compare protein per 100 calories alongside declared macros.
- Inspect the source and verification state behind a value.
- Check which catalog fields still lack reliable evidence.

## Current limits

The retained catalog reflects configured free and first-party sources, not the
whole Indian market. Its latest published evidence date is shown in the app.
Protein Index is a reference, not medical or dietary advice.
